# Nocter v0.73.0 Release Notes

Nocter v0.73.0 extends flow-sensitive safety proof to relationships between values and borrowed
view lengths. More practical slice, text, iterator, and scanner operations can now state truthful
`notrap` contracts without unchecked access or backend inference.

## Relational Safety Proof

The checker records strict and non-strict order between stable values and semantic view lengths.
It closes those relations transitively, rejects contradictory paths as unreachable, and intersects
semantic facts at control-flow joins. Checked unsigned subtraction and bounded cursor advancement
consume the same proof authority as indexed access.

Mutable locals, fields, and tuple projections have structural place identities. Writes invalidate
only affected facts when the exact place is known; calls with opaque alias carriers conservatively
discard value facts. Loop bodies are checked from repeatable invariants rather than facts that are
true only before the first iteration.

Every checked index and arithmetic operation still freezes a closed disposition. MIR and Machine
transport it without source reasoning, and ARM64 implements the selected check behavior.

## Borrowed Ranges and Traversal

Readonly and readwrite slice range construction now separates relational range proof from
recoverable address arithmetic. Borrowed text validates UTF-8 boundaries through one canonical
upper-bound path. Both APIs publish `noalloc notrap` after complete source-body validation.

Closed empty, one-item, readonly-view, and readwrite-view iterators now publish verified guarantees
for construction, advance, and exact remaining length. `Vec` exposes explicit verified borrowed
iterators. UTF-8 byte and scalar iteration gains verified construction, while scanner windows and
cursors publish guarantees for operations whose arithmetic and boundary checks are complete.

Generic adapters and operations that invoke unconstrained callbacks, decoders, comparisons,
destruction, or invariant-abort paths remain conservatively unqualified. The release does not add
unchecked indexing, user proof assertions, dependent types, an SMT solver, or target-specific
source proof.

## Correctness and Compatibility

Failure to prove safety preserves the runtime check and is not an error unless source explicitly
promises `notrap`. Existing valid v0.72.0 source remains valid. v0.73.0 adds stronger accepted
bodies and standard contracts without adding syntax or changing ordinary runtime semantics.
