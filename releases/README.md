# Nocter Releases

This directory is the user-facing record of published Nocter releases. Language rules live in the
[specification](../spec/README.md); release notes summarize changes and supported distribution
boundaries without redefining those rules.

## Latest Published Release

**Nocter v0.24.0** is the latest published release. It supports the `arm64-darwin` host and target.

- [Read the v0.24.0 release notes](v0.24.0.md)
- [Download v0.24.0 from GitHub Releases](https://github.com/rvo-jp/nocter/releases/tag/v0.24.0)
