# Nocter Downloads

Use the [installation guide](../README.md) for the currently supported release and host/target.
Published archives are available from [GitHub Releases](https://github.com/rvo-jp/nocter/releases).

Language and tooling behavior belongs to the [specification](../spec/README.md), and library
contracts to the [standard library](../std/README.md). Exact previous source and specification
states are preserved by [Git tags](https://github.com/rvo-jp/nocter/tags).
