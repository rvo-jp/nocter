# Nocter Releases

This directory is the user-facing record of published Nocter releases and the next qualified
candidate. Language rules live in the [specification](../spec/README.md); release notes summarize
changes and supported distribution boundaries without redefining those rules.

## Latest Published Release

**Nocter v0.4.0** is the latest published release. It supports the `arm64-darwin` host and target.

- [Read the v0.4.0 release notes](v0.4.0.md)
- [Download v0.4.0 from GitHub Releases](https://github.com/rvo-jp/nocter/releases/tag/v0.4.0)

## Qualified Candidate

**Nocter v0.5.0** has completed repository and packaged-home qualification but is not published.
Its notes describe the frozen candidate for review; users should install v0.4.0 until v0.5.0 is
published.

- [Read the v0.5.0 candidate notes](v0.5.0.md)
