# Release Packaging Inputs

This directory contains metadata inputs for the local release image generated by
`../compiler/scripts/package-local-release.sh`.

- `VERSION` is copied to `dist/.nocter/VERSION`.
- `MANIFEST.json` is copied to `dist/.nocter/MANIFEST.json`.
- Standard-library source is tracked separately in `../std/` and copied to
  `dist/.nocter/std/`.

Generated `dist/.nocter/` output is not committed to git.
