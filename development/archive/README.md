# Archived Development Material

This directory preserves superseded development documents without publishing them as active
contributor guidance. Its contents are not normative and are excluded from the generated website.

The `legacy-compiler-design/` documents describe the compiler removed at the start of the v0.14.0
specification-first rewrite. Do not consult them when defining language behavior, designing the new
compiler, writing conformance cases, or resolving an ambiguity. Git history and published release
records remain the appropriate sources for explicitly requested historical research.
