# v0.30.0 Release Preparation

**Status: release candidate qualified; publication active (2026-09-03).** This record owns the
candidate identity, qualification contract, and local artifact evidence. Publication is explicitly
authorized and must reuse the qualified archive recorded below.

## Release Boundary

v0.30.0 adds one synchronous subprocess operation for exact executable paths. `Command` owns its
validated path and arguments, inherits current process state, consumes itself into one create-and-
reap operation, and returns `ExitStatus`. Exec rejection crosses a private close-on-exec channel and
cannot be confused with a child exit code. The public `subprocess-status` package carries the same
contract through native execution, formatter, editor, and installed-home boundaries.

The [Phase 5 review](../reviews/v0.30.0-phase-5.md) found no remaining correctness or architecture
finding. Public release notes are [`../../releases/v0.30.0.md`](../../releases/v0.30.0.md). Root
download links and the public release index advance to v0.30.0 in the separate publication commit.
