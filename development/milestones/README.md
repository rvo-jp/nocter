# Development Milestones

This directory owns the scope, acceptance criteria, qualification, and publication state of the
active release candidate. Public language behavior belongs in `spec/`; compiler architecture belongs
in `development/docs/`.

- [v0.5.0 Candidate Record](v0.5.0.md)

After publication, freeze the candidate record under `development/releases/` and begin a separate
milestone document for the next version.
