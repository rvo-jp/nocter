# Development Milestones

This directory contains one active development milestone and historical milestone records.
Public language behavior belongs in [`spec/`](../../spec/README.md); published qualification belongs
in [`development/releases/`](../releases/README.md).

## Active Milestone

The [v0.19.0 milestone](v0.19.0.md) has completed Phase 0 filesystem traversal and proceeds next to
Phase 1 streaming text input. The milestone owns scope and completion criteria; the handoff owns
only the next concrete action.
