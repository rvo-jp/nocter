# v0.26.0 Release Preparation

**Status: release candidate qualified; publication pending (2026-09-02).** This record owns the
candidate identity, qualification contract, and final local artifact evidence. Publication requires
separate explicit authorization and will receive an immutable record under `development/releases/`.

## Release Boundary

v0.26.0 adds normalized non-negative `Duration` values, opaque monotonic `Instant` observations,
checked duration arithmetic, and blocking `time.sleep`. The public surface does not expose target
ticks, clock identifiers, syscall details, or calendar representations. All public time operations
publish `noalloc`; sleep makes no non-blocking or realtime promise.

The compiler owns three closed target primitive roles for monotonic observation, counter frequency,
and wrapping subtraction. ARM64 emits an instruction-ordered counter observation. The standard
library alone owns counter conversion, normalization, rounding, interruption retry, chunking, and
public failure policy. The bundled standard declaration profile is one physical locator authority
outside Session.

The public release notes are [`../../releases/v0.26.0.md`](../../releases/v0.26.0.md). The root
download link and public release index deliberately remain on v0.25.0 until publication.
