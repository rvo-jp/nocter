# v0.42.0 Release Preparation

**Status: published and externally audited (2026-09-09).** This record owns the release-candidate
identity, qualification contract, and retained local artifact evidence. The published asset reused
the recorded archive without rebuilding or replacing it.

## Release Boundary

v0.42.0 adds an asynchronous HTTP/1.1 client over the structured computation, executor, reactor,
and TCP foundation from v0.41.0. It preserves one request policy, final-response selector, body
decoder, response owner, and timeout authority across synchronous and asynchronous APIs. Practical
request constructors, text mutation, complete asynchronous body collection, a deterministic
loopback example, and semantic editor coverage complete the application-facing surface.

The [milestone](v0.42.0.md) and [Phase 5 review](../reviews/v0.42.0-phase-5.md) define the closed
implementation. Public release notes are
[`../../../releases/v0.42.0.md`](../../../releases/v0.42.0.md). Root download links, specification
status, and the public release index identify v0.42.0 in the publication commit.

## Qualification Contract

The clean release-content commit must pass:

1. independent complete compiler gates in distinct disposable Cargo targets;
2. repository metadata, benchmark-helper tests, pinned Unicode reproduction, formatting,
   warnings-denied all-target Clippy, all enabled locked workspace tests, no-default-features
   checking, and warnings-denied Rust documentation;
3. deterministic generated website reproduction and repository whitespace validation;
4. the explicit public-HTTPS dependency-acquisition test;
5. two independent optimized package builds with byte-identical archives and recursively identical
   installed homes;
6. fresh installed-home checks for version, diagnosis, help, initialization, locked/offline check
   and test, deterministic package graphs, native build, run, and direct execution;
7. every public example and its exact process contract, including asynchronous HTTP request
   transmission, response selection, fragmented body decoding, timeout, and cancellation ownership;
8. framed LSP analysis of installed public contracts and implementation sources;
9. proof that qualification commands do not mutate the installed home and that changing either the
   compiler or one standard-library source invalidates it.
