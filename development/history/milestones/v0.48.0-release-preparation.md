# v0.48.0 Release Preparation

**Status: published and externally audited (2026-09-12).** This record owns the release-candidate
identity, qualification contract, retained local artifact evidence, and publication boundary. The
published asset reused the retained qualified archive without rebuilding or replacing it.

## Release Boundary

v0.48.0 completes generic owning buffered byte I/O for both execution surfaces. Unqualified
`BufReader<R>` and `BufWriter<W>` are executor-safe adapters over `Reader` and `Writer`.
`BlockingBufReader<R>` and `BlockingBufWriter<W>` provide the explicit synchronous surface over
`BlockingReader` and `BlockingWriter`. Buffering, line normalization, flush, ownership, failure,
and cancellation policy are transport-independent and no longer tied to `File`.

The [milestone](v0.48.0.md) owns the completed implementation. The
[final review](../reviews/v0.48.0-phase-5.md) records the closed model and complete implementation
gate. Public candidate notes are [`../../../releases/v0.48.0.md`](../../../releases/v0.48.0.md).
Root downloads, specification publication status, and the public release index remain at v0.47.0
until publication.

The clean release-content commit must pass:

1. the complete compiler gate in a disposable Cargo target;

   warnings-denied all-target Clippy, every enabled locked workspace test, no-default-features

3. deterministic generated website reproduction and repository whitespace validation;
4. two independent optimized package builds with byte-identical archives and recursively identical
   installed homes;

   and test, deterministic package graphs, native build, run, and direct execution;
6. every public example and its exact process contract, including generic blocking and async

7. framed LSP analysis of installed public contracts and implementation sources;
8. proof that qualification commands do not mutate the installed home and that changing either the
   compiler or one standard-library source invalidates it.
