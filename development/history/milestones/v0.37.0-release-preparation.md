# v0.37.0 Release Preparation

**Status: qualified; publication authorized (2026-09-06).** This record owns the release-candidate
identity, qualification contract, and retained local artifact evidence. Publication must reuse the
recorded archive without rebuilding or replacing it.

## Release Boundary

v0.37.0 improves compiler, editor, and development-verification performance without changing
source semantics, diagnostics, native ABI, generated-program behavior, or LSP meaning. It gives
discovery one immutable compile input, replaces complete type-prefix maps with persistent cursors,
shares one body-syntax projection authority, and separates source-neutral relation analysis from
exact-current semantic assembly. Workspace test binaries now use the optimization level justified
by their compiler-heavy workload, and duplicated whole-example compilation was removed from the
weaker test layer.

The [milestone](v0.37.0.md) and
[performance closure review](../reviews/v0.37.0-performance-closure.md) define the closed
implementation. Public release notes are
[`../../../releases/v0.37.0.md`](../../../releases/v0.37.0.md). The root download links,
specification status, and public release index identify v0.37.0 in the publication commit.
