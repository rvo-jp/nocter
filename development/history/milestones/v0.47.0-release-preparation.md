# v0.47.0 Release Preparation

**Status: qualified; publication authorization required (2026-09-12).** This record owns the
release-candidate identity, qualification contract, retained local artifact evidence, and
publication boundary. No tag, push, upload, or public latest-release change is authorized by
preparation alone.

## Release Boundary

v0.47.0 gives executor-safe byte streams one generic public contract. Unqualified `Reader` and
`Writer` are canonical asynchronous interfaces, while synchronous code uses the explicit
`BlockingReader` and `BlockingWriter` contracts. Generic async defaults own ordinary whole-stream,
UTF-8, flush, text, and line behavior once; TCP, TLS, and HTTP retain only transport-specific
progress, timeout, framing, and close policy.

The [milestone](v0.47.0.md) owns the completed implementation and reviews. Public candidate notes
are [`../../../releases/v0.47.0.md`](../../../releases/v0.47.0.md). Root download links,
specification publication status, and the public release index remain at v0.46.0 until an explicitly
authorized publication commit.
