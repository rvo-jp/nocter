# v0.44.0 Release Preparation

**Status: published and externally audited (2026-09-11).** This record owns the release-candidate
identity, qualification contract, retained local artifact evidence, and publication boundary. The
published asset reused the retained qualified archive without rebuilding or replacing it.

## Release Boundary

v0.44.0 separates asynchronous producer execution from future value types. `async` is now an
explicit function or method modifier, while `future T` is the structural move-only value returned
by a deferred invocation. Execution kind is fixed once from declaration syntax and no longer
inferred from a normalized result type.

The [milestone](v0.44.0.md) defines the closed implementation and Phase 4 review. Public candidate
notes are [`../../../releases/v0.44.0.md`](../../../releases/v0.44.0.md). Root download links,
specification status, and the public release index remain at v0.43.0 until the publication commit.

## Qualification Contract

The clean release-content commit must pass:

1. independent complete compiler gates in disposable Cargo targets;
2. repository metadata, benchmark-helper tests, pinned Unicode reproduction, formatting,
   warnings-denied all-target Clippy, all enabled locked workspace tests, no-default-features
   checking, and warnings-denied Rust documentation;
3. deterministic generated website reproduction and repository whitespace validation;
4. two independent optimized package builds with byte-identical archives and recursively identical
   installed homes;
5. fresh installed-home checks for version, diagnosis, help, initialization, locked/offline check
   and test, deterministic package graphs, native build, run, and direct execution;
6. every public example and its exact process contract, including asynchronous TCP and HTTP,
   timeout, cancellation, and terminal ownership;
7. framed LSP analysis of installed public contracts and implementation sources;
8. proof that qualification commands do not mutate the installed home and that changing either the
   compiler or one standard-library source invalidates it.

The earlier complete Phase 4 gate remains useful evidence, but release qualification executes
again against the commit carrying the final `0.44.0` identity.
