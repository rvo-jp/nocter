# v0.73.0: Relational Safety and Verified Traversal

**Status: in progress.** This milestone extends checking-owned safety proof from independent value
ranges to relationships between stable values and borrowed-view lengths. It then uses those facts
to make practical traversal and range construction publish truthful `notrap` contracts. It does not
add a new source guarantee modifier.

## Goal

Let ordinary source code prove the safety conditions used by range and iterator implementations:
one offset is at most another, a cursor remains below its view length, and advancing a bounded
unsigned cursor cannot overflow. Checking remains the sole proof authority. Checked operations
retain the resulting disposition, while MIR, Machine, native lowering, and editor tooling consume
or present that frozen result without reconstructing the proof.

## Completion Definition

v0.73.0 is complete when:

- branch facts represent strict and non-strict order between stable values and semantic view
  lengths;
- transitive order is normalized before control-flow joins, so equivalent facts survive different
  source spellings;
- contradictory relations make a path unreachable instead of admitting an inconsistent proof;
- unsigned subtraction and bounded cursor advance consume relational facts through the existing
  checked arithmetic disposition;
- mutable traversal uses explicit place identity and invalidates only facts affected by a write or
  alias-capable call;
- loop continuation and exit facts are computed without assuming the first iteration is the only
  iteration;
- useful slice, text, and iterator implementations publish `notrap` only after complete source-body
  validation; and
- focused checker, standard-library, editor, native, documentation, and deterministic packaging
  gates pass from one clean release candidate.

## Phases

### Phase 0 — Relational Fact Domain

**Status: complete.** The special-purpose length relation is replaced by one transitively closed
order domain over stable values and semantic view lengths. Numeric constant intervals remain the
separate numeric domain. Branches add normalized order facts, joins intersect their semantic
closure, and checked unsigned subtraction and bounded increment consume the same relation
authority. The [Phase 0 review](../reviews/v0.73.0-phase-0.md) records the authority and regression
audit.

### Phase 1 — Place-Sensitive Mutation

**Status: complete.** Writable locals, field projections, and tuple projections now use structural
place identities. Immutable copies preserve relevant facts; reborrowed locals canonicalize to their
source place. Assignment and alias-capable calls invalidate facts through one explicit mutation
contract. Exact places preserve unrelated fields, while an opaque alias carrier conservatively
drops all value facts. The concrete mutable-view advance implementation now validates its authored
`notrap` body. The [Phase 1 review](../reviews/v0.73.0-phase-1.md) records the alias and invalidation
audit.

### Phase 2 — Loop Invariants

**Status: complete.** Repeated conditions and bodies are now checked from a conservative invariant
containing only facts rooted in non-aliasable immutable storage. The condition may establish fresh
facts for every entered iteration. Normal exits use the repeated-condition state rather than the
first-entry state, and explicit breaks join through their checked body state. The
[Phase 2 review](../reviews/v0.73.0-phase-2.md) records the repeatability audit.

### Phase 3 — Borrowed Range Construction

**Status: planned.** Close the pointer-arithmetic and boundary proofs needed by borrowed slice and
text range construction without unchecked source operations or backend-owned reasoning.

### Phase 4 — Verified Traversal Adoption

**Status: planned.** Apply the completed proof model to standard iterators, scanners, and borrowed
range observers. Publish guarantees only where the physical implementation validates as a complete
body.

### Phase 5 — Qualification

**Status: planned.** Audit proof authority, LSP presentation, native execution, public
documentation, deterministic packaging, and release evidence before publication.

## Deliberate Limits

The milestone does not add dependent types, an SMT solver, user-authored proof assertions,
unchecked indexing, `unsafe`, or target-specific proof rules. Failure to prove safety preserves the
runtime check and only rejects code that explicitly promises `notrap`.
