# v0.53.0 Release Preparation

**Status: qualified release candidate; publication pending.** This record owns the
release-candidate identity, qualification contract, and retained local artifact evidence.
Publication evidence belongs in a later immutable release audit.

## Release Boundary

v0.53.0 establishes the standard-library foundations for structured network services. JSON compact
generation now uses one effect-neutral incremental encoder, dynamic `TaskGroup<T>` owns a
runtime-sized set of child computations, and `std/http` exposes an asynchronous one-request server
typestate with bounded decoding, explicit response authority, and operation deadlines.

The public `http-service` example composes these contracts into a two-connection service without a
compiler-recognized framework, detached task, hidden server registry, or implicit capacity policy.
It drives successful and explicit no-response handler outcomes concurrently with three clients.

The [milestone](v0.53.0.md) owns the completed implementation. The [closure
review](../reviews/v0.53.0-phase-5.md) records the final compiler-boundary correction and complete
repository gate. Public candidate notes are
[`../../../releases/v0.53.0.md`](../../../releases/v0.53.0.md). Published-version surfaces continue
to select v0.52.0 until publication succeeds.

## Qualification Contract

The clean release-content commit must pass:

1. the complete compiler gate in a disposable Cargo target;
2. repository metadata, benchmark helpers, pinned Unicode reproduction, formatting,
   warnings-denied all-target Clippy, every enabled locked workspace test, no-default-features
   checking, and warnings-denied Rust documentation;
3. deterministic out-of-tree website generation and repository whitespace validation;
4. two independent optimized package builds with byte-identical archives and recursively identical
   installed homes;
5. fresh installed-home checks for version, diagnosis, help, initialization, locked/offline check
   and test, deterministic graphs, native build, run, and direct execution;
6. every public example and the exact filesystem, streaming, network, HTTP, TLS, process, dynamic
   task-group, and bounded HTTP service contracts;
7. framed LSP analysis of installed public contracts and implementation sources;
8. proof that qualification commands do not mutate the installed home and that changing either the
   compiler or one standard-library source invalidates it.
