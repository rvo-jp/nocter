# v0.36.0 Release Preparation

**Status: qualified; publication authorized (2026-09-06).** This record owns the release-candidate
identity, qualification contract, and retained local artifact evidence. Publication must reuse the
recorded archive without rebuilding or replacing it.

## Release Boundary

v0.36.0 adds normalized wall-clock instants, validated proleptic-Gregorian UTC calendar values,
strict RFC 3339 interchange, and filesystem modification times. Calendar and text-format policy
remain ordinary standard-library source; the compiler and target backend know only the existing
generic syscall, checked type, runtime representation, and machine ABI contracts.

The [milestone](v0.36.0.md) and
[final implementation review](../reviews/v0.36.0-final.md) define the closed implementation.
Public release notes are [`../../../releases/v0.36.0.md`](../../../releases/v0.36.0.md). The root
download links, specification status, and public release index identify v0.36.0 in the publication
commit.

## Qualification Contract

The clean release-content commit must pass:

1. two independent complete compiler gates in distinct disposable Cargo targets;
2. repository metadata, pinned Unicode reproduction, formatting, warnings-denied all-target
   Clippy, all enabled locked workspace tests, no-default-features checking, and warnings-denied
   Rust documentation in both gates;
3. deterministic generated website reproduction and repository whitespace validation;
4. the explicit public-HTTPS dependency-acquisition test;
5. two independent optimized package builds with byte-identical archives and recursively identical
   installed homes;
6. fresh installed-home checks for version, diagnosis, help, initialization, locked/offline check
   and test, deterministic package graphs, native build, run, and direct execution;
7. every public example and its exact process contract, including wall-clock observation and
   filesystem modification-time conversion;
8. framed LSP analysis of installed public contracts and implementation sources, including the
   wall-clock, RFC 3339, and metadata surfaces;
9. proof that qualification commands do not mutate the installed home and that changing either the
   compiler or one standard-library source invalidates it.
