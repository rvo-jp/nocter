## Release Boundary

v0.55.0 adds one explicit, owning representation for heterogeneous runtime callables. `any func`,
`any &func`, and `any &+func` preserve the authored callable contract, capability, guarantees,
result provenance, capture ownership, and destruction after erasure. Checked execution selects
erasure and dispatch once; executable closure, MIR, Machine, and ARM64 layers consume closed
identities without source-name lookup or repeated semantic selection.

The standard HTTP library uses readonly erased handlers to provide deterministic exact and named
segment routing. `RequestTarget` owns path and query interpretation once, while applications retain
task admission, handler execution, response policy, connection reuse, and graceful shutdown. The
complete public service covers exact and parameter routes, query decoding, handler failure,
malformed input, timeout, 32 KiB streaming, sequential keep-alive, bounded tasks, and draining.

The [milestone](v0.55.0.md) owns the completed implementation. The [closure
review](../reviews/v0.55.0-phase-5.md) records the final authority audit and complete repository
gate. Public candidate notes are
[`../../../releases/v0.55.0.md`](../../../releases/v0.55.0.md). Root downloads, specification
publication status, and the public release index now select v0.55.0.

The clean release-content commit must pass:

1. the complete compiler gate in a disposable Cargo target;
2. repository metadata, performance helpers, pinned Unicode reproduction, formatting,
   warnings-denied all-target Clippy, every enabled locked workspace test, no-default-features
   checking, and warnings-denied Rust documentation;
3. deterministic out-of-tree website generation and repository whitespace validation;
4. two independent optimized package builds with byte-identical archives and recursively identical
   installed homes;
5. fresh installed-home checks for version, diagnosis, help, initialization, locked/offline check
   and test, deterministic graphs, native build, run, and direct execution;
6. every public example and the exact filesystem, streaming, network, HTTP, TLS, process, task,
   routing, persistent-connection, and graceful-service contracts;
7. interactive LSP initialization, dynamic capability registration, hover, completion, navigation,
   edited-source diagnostics, recovery, and shutdown against installed public and implementation
   sources;
8. proof that qualification commands do not mutate the installed home and that changing either the
   compiler or one standard-library source invalidates it.
