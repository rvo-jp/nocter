# v0.43.0 Release Preparation

**Status: qualified; publication authorized (2026-09-10).** This record owns the release-candidate
identity, qualification contract, and retained local artifact evidence. Publication must reuse the

## Release Boundary

v0.43.0 adds authenticated TLS client streams and HTTPS to the synchronous and asynchronous HTTP
client. Network.framework supplies one provider owner and ordered callback-event model for plain
TCP and TLS. Security.framework supplies system trust, hostname authentication, certificate
validity, custom-root augmentation, and TLS 1.2-or-newer policy. HTTPS requires negotiated
HTTP/1.1 ALPN before exposing a connection to the existing HTTP codec.

The [milestone](v0.43.0.md) and
[Phase 6 review](../reviews/v0.43.0-phase-6.md) define the closed implementation. Public candidate
notes are [`../../../releases/v0.43.0.md`](../../../releases/v0.43.0.md). Root download links,
specification status, and the public release index remain at v0.42.0 until the publication commit.
