# v0.60.0 Release Preparation

**Status: qualified; publication pending.** This record owns the release-candidate identity,
qualification contract, and retained local artifact evidence. Publication evidence will be

## Release Boundary

v0.60.0 turns Nocter's byte codecs, fixed-capacity storage, CRC-32, readers, and path contracts into
one bounded compressed-archive pipeline. `std/internal/deflate` owns bit order and canonical
Huffman tables. `std/compress` owns raw DEFLATE state, the 32 KiB history window, gzip member
framing, and integrity progress. `std/archive` owns POSIX ustar headers, entry boundaries, bounded
metadata, and normalized relative paths.

Blocking and asynchronous adapters drive the same compression and archive cursors through the
existing `std/io` contracts. The `archive-inspect` package owns accepted entry kinds, explicit
compressed-input, declared-output, entry-count, and path limits, duplicate rejection, and delayed
report publication. The [milestone](v0.60.0.md) and [Phase 6
review](../reviews/v0.60.0-phase-6.md) own the completed implementation scope. Public candidate
notes are [`../../../releases/v0.60.0.md`](../../../releases/v0.60.0.md).

1. the complete compiler gate in a disposable Cargo target;

   warnings-denied all-target Clippy, every enabled locked workspace test, no-default-features

3. deterministic out-of-tree website generation and repository whitespace validation;
4. two independent optimized package builds with byte-identical archives and recursively identical
   installed homes;
5. fresh installed-home checks for version, diagnosis, help, initialization, locked/offline check
   and test, deterministic graphs, native build, run, and direct execution;
6. every public example, all declared `archive-inspect` tests, its real-file process contract, and
   the retained exact binary-record wire-image contract;
7. interactive LSP initialization, dynamic capability registration, semantic queries,
   edited-source diagnostics, recovery, and shutdown against installed compression, archive,
   codec, checksum, storage, error, and Unicode public and implementation sources; and
8. proof that qualification commands do not mutate the installed home and that changing either the
   compiler or one standard-library source invalidates it.
