# v0.59.0 Release Preparation

**Status: published and externally audited.** This record owns the release-candidate identity,
qualification contract, and retained local artifact evidence. The immutable publication evidence
is recorded in [`../release-audits/v0.59.0.md`](../release-audits/v0.59.0.md).

## Release Boundary

v0.59.0 completes canonical variable-width integer processing and integrity-checked append-only
records on the v0.58.0 scalar byte foundation. `std/bytes` owns prefix-decode classification,
unsigned LEB128, ZigZag signed encoding, and signed fixed-width bit projection. `std/checksum`
independently owns allocation-free one-shot and incremental ISO-HDLC CRC-32.

`scan.ByteCursor` remains the sole borrowed position authority, `fixed.ByteBuffer<N>` remains the
bounded staging authority, and `Vec<u8>` remains the dynamic growth authority. The practical
`binary-record` package owns record framing and damaged-tail policy while its blocking and
asynchronous transports call the same decoder. The [milestone](v0.59.0.md) and
[Phase 5 review](../reviews/v0.59.0-phase-5.md) own the completed implementation scope. Public
candidate notes are [`../../../releases/v0.59.0.md`](../../../releases/v0.59.0.md).

## Qualification Contract

The clean release-content commit must pass:

1. the complete compiler gate in a disposable Cargo target;
2. repository metadata, performance helpers, pinned Unicode reproduction, formatting,
   warnings-denied all-target Clippy, every enabled locked workspace test, no-default-features
   checking, and warnings-denied Rust documentation;
3. deterministic out-of-tree website generation and repository whitespace validation;
4. two independent optimized package builds with byte-identical archives and recursively identical
   installed homes;
5. fresh installed-home checks for version, diagnosis, help, initialization, locked/offline check
   and test, deterministic graphs, native build, run, and direct execution;
6. every public example plus declared tests, native execution, and exact 46-byte output for the
   integrity-checked binary-record package;
7. interactive LSP initialization, dynamic capability registration, semantic queries, edited-source
   diagnostics, recovery, and shutdown against installed public and implementation sources for
   fixed and variable codecs, checksum, cursor, dynamic storage, errors, and Unicode; and
8. proof that qualification commands do not mutate the installed home and that changing either the
   compiler or one standard-library source invalidates it.
