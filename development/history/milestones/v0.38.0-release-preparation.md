# v0.38.0 Release Preparation

**Status: qualified and ready for separately authorized publication (2026-09-07).** This record
owns the release-candidate identity, qualification contract, and retained local artifact evidence.
It does not claim publication or authorize a tag, push, upload, or public latest-release change.

## Release Boundary

v0.38.0 adds complete IEEE 754 binary32 and binary64 values across source syntax, checking,
compile-time evaluation, Machine ABI, native ARM64 execution, standard numeric text, formatting,
interpolation, JSON conversion, examples, and editor queries. The target evaluator owns exact
compile-time bits, Machine owns transport classification, and the standard library owns one runtime
decimal parser and one shortest-decimal generator. Floating comparison remains partial; the new
`TotalOrder` contract identifies types that may be used by total-order consumers such as sorting.

The [milestone](v0.38.0.md) and [Phase 3 review](../reviews/v0.38.0-phase-3.md) define the closed
implementation. Public candidate notes are
[`../../../releases/v0.38.0.md`](../../../releases/v0.38.0.md). Root download links, specification
status, and the public release index remain at v0.37.0 until separately authorized publication.

## Qualification Contract

The clean release-content commit must pass:

1. independent complete compiler gates in distinct disposable Cargo targets;
2. repository metadata, benchmark-helper tests, pinned Unicode reproduction, formatting,
   warnings-denied all-target Clippy, all enabled locked workspace tests, no-default-features
   checking, and warnings-denied Rust documentation;
3. deterministic generated website reproduction and repository whitespace validation;
4. the explicit public-HTTPS dependency-acquisition test;
5. two independent optimized package builds with byte-identical archives and recursively identical
   installed homes;
6. fresh installed-home checks for version, diagnosis, help, initialization, locked/offline check
   and test, deterministic package graphs, native build, run, and direct execution;
7. every public example and its exact process contract, including floating-point integration;
8. framed LSP analysis of installed public contracts and implementation sources;
9. proof that qualification commands do not mutate the installed home and that changing either the
   compiler or one standard-library source invalidates it.
