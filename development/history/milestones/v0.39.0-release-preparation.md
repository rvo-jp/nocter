# v0.39.0 Release Preparation

**Status: qualified; publication authorized (2026-09-07).** This record owns the release-candidate
identity, qualification contract, and retained local artifact evidence. Publication must reuse the
recorded archive without rebuilding or replacing it.

## Release Boundary

v0.39.0 adds target-independent numeric IPv4 and IPv6 values, synchronous TCP streams and
listeners, boundary-preserving UDP datagrams, and finite monotonic operation timeouts. Public
socket values uniquely own their descriptors, native layouts remain inside the Darwin adapter, and
the compiler gives network APIs no special meaning.

The [milestone](v0.39.0.md) and [Phase 5 review](../reviews/v0.39.0-phase-5.md) define the closed
implementation. Public release notes are
[`../../../releases/v0.39.0.md`](../../../releases/v0.39.0.md). The root download links,
specification status, and public release index identify v0.39.0 in the publication commit.

   checking, and warnings-denied Rust documentation;
3. deterministic generated website reproduction and repository whitespace validation;
4. the explicit public-HTTPS dependency-acquisition test;

   installed homes;
6. fresh installed-home checks for version, diagnosis, help, initialization, locked/offline check

7. every public example and its exact process contract, including TCP, UDP, and timeout integration;
8. framed LSP analysis of installed public contracts and implementation sources;
9. proof that qualification commands do not mutate the installed home and that changing either the
