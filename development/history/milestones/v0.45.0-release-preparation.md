# v0.45.0 Release Preparation

**Status: published and externally audited (2026-09-11).** This record owns the release-candidate
identity, qualification contract, retained local artifact evidence, and publication boundary. The
published asset reused the retained qualified archive without rebuilding or replacing it.

## Release Boundary

v0.45.0 makes nonblocking drive a universal property of `future T`, represents synchronous
external waiting with the positive `blocking` callable effect, makes asynchronous network, TLS,
HTTP, and sleep operations the canonical base-name APIs, and adds deterministic structured races
and timeout composition.

The [milestone](v0.45.0.md) owns the completed implementation and Phase 5 review. Public candidate
notes are [`../../../releases/v0.45.0.md`](../../../releases/v0.45.0.md). Root download links,
specification publication status, and the public release index remain at v0.44.0 until the
publication commit.

## Candidate Identity

## Qualification Contract

The clean release-content commit must pass:

1. the complete compiler gate in a disposable Cargo target;
2. repository metadata, benchmark-helper tests, pinned Unicode reproduction, formatting,
   warnings-denied all-target Clippy, every enabled locked workspace test, no-default-features
   checking, and warnings-denied Rust documentation;
3. deterministic generated website reproduction and repository whitespace validation;
4. two independent optimized package builds with byte-identical archives and recursively identical
   installed homes;
5. fresh installed-home checks for version, diagnosis, help, initialization, locked/offline check
   and test, deterministic package graphs, native build, run, and direct execution;
6. every public example and its exact process contract, including structured task race and timeout,
   asynchronous TCP, TLS, and HTTP, cancellation, and terminal ownership;
7. framed LSP analysis of installed public contracts and implementation sources;
8. proof that qualification commands do not mutate the installed home and that changing either the
   compiler or one standard-library source invalidates it.

The completed Phase 5 gate remains useful evidence, but release qualification executes again
against the commit carrying the final `0.45.0` identity.
