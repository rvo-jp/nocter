# v0.46.0 Release Preparation

**Status: qualified and ready for publication (2026-09-11).** This record owns the release-candidate
identity, qualification contract, retained local artifact evidence, and publication boundary. No
tag, push, upload, or public latest-release change is authorized by preparation alone.

## Release Boundary

v0.46.0 completes UDP as an executor-safe networking surface. One `UdpSocket` owner supports
immediate setup and address observation, canonical asynchronous transfers, explicit asynchronous
deadlines, and clearly named blocking twins. Closed target operations keep one nonwaiting datagram
attempt out of the generic blocking syscall boundary, while standard source remains the sole owner
of retry, timeout, truncation, and public failure policy.

The [milestone](v0.46.0.md) owns the completed implementation and Phase 5 review. Public candidate
notes are [`../../../releases/v0.46.0.md`](../../../releases/v0.46.0.md). Root download links,
specification publication status, and the public release index remain at v0.45.0 until an explicitly
authorized publication commit.
