# v0.41.0 Release Preparation

**Status: qualified; publication authorized (2026-09-09).** This record owns the release-candidate
identity, qualification contract, and retained local artifact evidence. Publication must reuse the
recorded archive without rebuilding or replacing it.

## Release Boundary

v0.41.0 adds lazy owning `async T` computations, consuming `await`, compiler-generated resumable
state machines, deterministic cancellation and destruction, a single-threaded executor, a Darwin
kqueue reactor, structured two-child `task.join`, and public asynchronous time and TCP APIs. The
checked program fixes suspension and ownership meaning; Machine fixes lifecycle and layout; the
target consumes those frozen products without reinterpreting semantic state.

The [milestone](v0.41.0.md) and [Phase 5 review](../reviews/v0.41.0-phase-5.md) define the closed
implementation. Public release notes are
[`../../../releases/v0.41.0.md`](../../../releases/v0.41.0.md). Root download links, specification
status, and the public release index identify v0.41.0 in the publication commit.
