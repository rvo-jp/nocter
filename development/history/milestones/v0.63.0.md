# v0.63.0: Cryptographic Randomness

**Status: implementation complete and reviewed (2026-09-20); release preparation has not begun.**

## Goal

Expose operating-system cryptographic entropy as one portable, allocation-free standard-library
contract, then build unbiased integer sampling and in-place shuffling on that contract. The
compiler must describe only the selected target operation; it must not know public random types,
errors, sampling policy, or collection algorithms.

The existing hash-table seed path is not a second entropy API. It becomes an internal consumer of
the same byte-filling authority used by `std/random`.

## Completion Definition

v0.63.0 is complete when all of the following are true:

- one target primitive fills a caller-owned byte range of an explicitly supplied length;
- one package-internal entropy adapter owns target request limits, retry policy, and raw failure
  classification;
- `std/random` can fill any mutable byte slice without allocation and reports unavailable entropy
  through a stable public error;
- a failed public fill leaves no partially generated output observable;
- full-width integer generation and bounded integer generation consume the same byte authority;
- bounded generation uses rejection sampling and introduces no modulo bias;
- in-place shuffling uses the bounded sampler and does not allocate or copy the collection;
- hash-table seeds consume the internal entropy adapter without retaining a hash-specific compiler
  primitive;
- deterministic tests isolate the sampling and permutation decision core below the public target
  adapter and cover rejection, boundaries, failure cleanup, and shuffle permutations; and
- complete compiler, editor, standard-library, documentation, installation, and packaging gates
  pass without a duplicate entropy or sampling implementation.

## Responsibility Boundaries

The selected target owns the native entropy operation and calling convention. Its primitive
accepts only a pointer and byte length and returns one target failure fact. It does not construct a
Nocter error, loop over target request limits, select random distributions, seed hashing, or know a
public standard-library type.

`std/internal/entropy` owns target request limits, repeated native calls, and exact completion. It
is the only standard-library module allowed to call the entropy primitive. It returns an internal
success or failure fact and does not choose public error text or terminate the process.

`std/random` owns the public failure vocabulary, output cleanup, scalar assembly, rejection
sampling, and in-place permutation. It does not expose native error numbers or promise a
deterministic generator.

`std/hash` remains authoritative for hash state and algorithm selection. It requests seed bytes
from the entropy adapter and retains its existing fail-stop policy when safe randomized collection
construction cannot obtain entropy.

## Phases

### Phase 0 — Entropy Authority

**Status: complete.** The runtime role now accepts one byte pointer and explicit length. The ARM64
selector validates that exact ABI and emits the native operation without inventing a seed width.
`std/internal/entropy` alone splits requests at the Darwin limit and retries interruption, while
`std/hash` consumes the adapter's target-independent completion result and owns its fail-stop
policy. Native conformance covers a non-word-sized request, and the complete compiler fast gate
passes.

- replace the hash-specific 64-bit primitive with a pointer-and-length entropy operation;
- move target adaptation from `std/internal/hash` to `std/internal/entropy`;
- route hash seeding through the shared internal adapter; and
- prove primitive selection, ABI lowering, visibility, and complete native execution.

### Phase 1 — Public Random Bytes and Scalars

**Status: complete.** `std/random` now exposes allocation-free byte filling and full-domain `u64`
and `usize` generation. The public layer converts the internal completion fact to the stable
`std.random.unavailable` failure, clears the complete caller-owned destination before exposing a
failure, and delegates scalar byte order to `std/bytes`. A native-session test exercises a
257-byte request and both scalar APIs through the released target path.

- add the checked `std/random` contract and stable failure category;
- fill arbitrary mutable byte slices in bounded target requests;
- clear the complete destination after any failed request; and
- build full-width unsigned scalar generation from canonical byte assembly.

### Phase 2 — Unbiased Sampling and Permutations

**Status: complete.** `below_u64` and `below_usize` reject the biased full-width prefix before
remainder reduction and reject zero before requesting entropy. `shuffle` applies allocation-free
Fisher-Yates to copyable or move-only slice elements. Sampling arithmetic and permutation steps
are isolated as deterministic decision functions, while native tests separately execute the
public entropy-backed path. The raw initialized-value exchange used by sorting and shuffling now
has one bounds-checked package-internal authority instead of two copies.

- implement bounded unsigned and `usize` sampling with rejection rather than remainder-only
  reduction;
- reject an empty bound before consuming entropy;
- implement allocation-free Fisher-Yates shuffling over mutable slices; and
- test deterministic decision inputs, rejection paths, and every small permutation boundary.

### Phase 3 — Adoption, Review, and Qualification

**Status: complete.** The runnable `random-choice` example crosses checking, target selection,
native materialization, and execution through public `std/random` declarations. The full authority
review found one stale map guide and no duplicate entropy, scalar assembly, bounded sampling, or
permutation implementation. The guide now describes the actual `HashState` boundary. Compiler,
standard-library, editor, documentation, installation-model, and packaging-metadata gates pass;
installed-archive release qualification remains intentionally owned by release preparation after
the version bump.

- add one runnable example that uses only the public contract;
- review compiler and standard source for duplicate entropy, byte assembly, or range-selection
  authority;
- generate the public documentation from the checked declaration and behavior guide; and
- run the complete disposable compiler gates, leaving versioned archive qualification to release
  preparation.
