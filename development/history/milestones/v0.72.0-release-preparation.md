# v0.72.0 Release Preparation

**Status: qualified release candidate (2026-09-26).** This record owns the v0.72.0 release-content
identity, qualification contract, and retained local artifact evidence. Publication and its public
audit remain separate steps, both explicitly authorized for this release.

## Release Boundary

v0.72.0 makes path-sensitive bounds and integer-arithmetic proof a checking-owned semantic product.
Checked operations retain a closed disposition, checked execution uses it for `notrap`, MIR and
Machine transport it without re-proof, and ARM64 implements complete runtime fallback checks. The
standard slice API adopts only the guarantees proved through this full path.

The [v0.72.0 milestone](v0.72.0.md) owns the implementation scope. Its five reviews record the
safety-disposition boundary, flow domain, dynamic bounds proof, arithmetic runtime closure, and
standard-library adoption. Public candidate notes are
[`../../../releases/v0.72.0.md`](../../../releases/v0.72.0.md).

## Candidate Identity

The release inputs agree on `0.72.0`:

7. every public example plus the complete process, filesystem, network, TLS, HTTP, durable-state,

9. proof that qualification commands do not mutate the installed home and that changing either the
   compiler or one standard-library source invalidates it.
