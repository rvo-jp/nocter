# v0.50.0 Phase 2 Recursive-traversal Review

Date: 2026-09-14

## Result

`std/fs.walk_dir` and its explicit blocking twin now yield one directory tree in depth-first order
with bounded memory, final-link classification, and no symbolic-link descent. This closes Phase 2.

## Authority Review

- `ReadDir` and `BlockingReadDir` remain the only descriptor owners and raw directory-record
  decoders. Traversal knows only their step and close contracts.
- `recursive_policy.nct` is the single owner of the shared 256-level bound and stable
  `std.fs.recursion_limit` failure. Removal and traversal depend on this policy instead of each
  other.
- `recursive_traversal.nct` alone owns depth-first ordering, root exclusion, traversal terminal
  state, and exact entry reclassification. Target records, syscalls, and worker jobs do not contain
  traversal policy.
- `directory.nct` keeps the `DirEntry` representation private and exposes narrow path projection
  and reclassification operations to traversal policy; traversal does not name snapshot fields.
- `symlink_metadata` is the descent authority. Directory-entry type hints are replaced by that
  exact final-link snapshot before an entry is returned, and never authorize descent themselves.

## Ownership and Cancellation Review

One walker retains a vector of owning directory streams, not a vector of discovered entries, so
memory is proportional to depth. Before an asynchronous step suspends, it replaces the public
owner state with `terminal` and transfers the entire vector into the future frame. Successful
completion restores the vector exactly once. Failure marks the walker finished and drops every
stream; cancellation drops the future-owned vector and cannot leave sibling streams available
after the active subtree was lost.

Clean exhaustion and explicit close are idempotent. Asynchronous close transfers the same complete
state and retires each stream through its existing executor-safe close contract. Destruction uses
the same state replacement and relies on each `ReadDir`'s close-once drop authority.

## Verification

Standard native tests cover nested traversal, exact entry count, metadata-backed regular and
symbolic-link classification, and non-descent through a link to an external directory. A complete
asynchronous native session walks a nested tree before recursive removal. Editor coverage resolves
both the blocking constructor and receiver-specific step method from the public contract.
