# v0.49.0 Phase 6 Review

## Result

No release-blocking Phase 6 issue remains. The reference application uses the public process, I/O,
buffer, task, and time contracts without introducing another process authority or compiler-known
source convention.

The application owns one structured computation graph. Generic `io.copy` transfers producer
stdout into consumer stdin while three ordinary reader computations capture producer stderr,
consumer stdout, and consumer stderr and two child computations perform exact observation. One
timeout owns that complete graph. The producer writes 73,728 bytes to both stdout and stderr and
the consumer returns 73,728 bytes; servicing either producer stream sequentially would deadlock.

## Cancellation and Failure Matrix

The native timeout test waits until an exact helper has written its PID and produced pipe data,
then cancels its pending wait. Cancellation destroys the owning `Child`; the harness subsequently
proves that the exact PID is no longer observable. This distinguishes termination-and-reap cleanup
from merely dropping a future or closing a descriptor.

The asynchronous closed-output test sends one mebibyte to a child that closes stdin immediately.
Together with the existing native matrix, qualification covers output beyond pipe capacity,
simultaneous stdout and stderr, early stdin closure, executable rejection, nonzero status, signal
termination, timeout, cancellation, and exact cleanup.

## Editor Contract

One ordinary pipeline source qualifies hover, definition and implementation navigation,
instantiated generic signature help, receiver-aware completion, semantic tokens, and inferred-type
inlay hints. Generic signature help reports the selected `ChildStdout`/`ChildStdin` arguments and
their `Reader`/`Writer` evidence from checked program facts. No editor feature reconstructs those
facts from source names or a parallel syntax meaning.

## Boundary Review

- The application adds no primitive role, public wrapper, syscall classifier, launch path, wait
  path, process-specific buffer, or cleanup registry.
- Timeout policy remains in `std/task`; process owners only implement lexical destruction.
- Exact cleanup is verified through external observation of the recorded PID rather than an
  internal cleanup flag.
- The public-example catalog remains the sole authority for executable fixtures and expected
  output; CLI tests select that contract rather than duplicating it.
- LSP qualification opens the same package source compiled by the example gates and consumes its
  checked declarations and interface evidence.
