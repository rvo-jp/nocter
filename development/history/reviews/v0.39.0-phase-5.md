# v0.39.0 Phase 5 Network Integration and Final Review

**Result: implementation and release-candidate qualification complete with no open v0.39.0
finding (2026-09-07).** Numeric addresses, TCP, UDP, and finite monotonic timeouts now cross
ordinary programs, native execution, installed standard-library use, and semantic editor queries
without a compiler-owned network exception.

## Practical Boundary

`examples/network-address.nct` is an explicit single-file program that parses and canonically
formats a bracketed IPv6 socket address. `examples/network-loopback` is an ordinary package split
between a tiny root adapter and one implementation source. It binds only numeric IPv4 loopback
addresses with kernel-selected ports, exchanges exact TCP and UDP payloads, and observes a finite
UDP receive timeout through `std.net.timed_out`. Neither example requires DNS, an external host, a
predicted free port, test-only source syntax, or a raw descriptor.

Both examples belong to the existing public-example authorities. The single-file corpus discovers,
builds, executes, and compares the address program's exact output. The package registry does the
same for the loopback application and rejects an unregistered package directory. The installed-home
system-example gate builds and executes the loopback package against a manifest-validated copied
standard library, proving that repository-path shortcuts are not required.

## Final Authority Audit

The review traced the full implementation and found the following single authorities:

1. `std/net` owns public address syntax, canonical text, socket types, datagram boundaries, timeout
   configuration, and stable error codes.
2. `std/internal/net/model` owns target-neutral address values crossing the policy/adapter boundary.
3. `std/internal/net/descriptor.nct` owns descriptor state, construction cleanup, retry, transfer
   progress, and selection of one operation deadline.
4. `std/internal/net/deadline.nct` owns monotonic remaining-time calculation and bounded logical poll
   intervals.
5. `std/internal/net/darwin` owns native records, constants, byte order, syscall classification,
   poll sentinel encoding, close-on-exec, IPv6-only configuration, and broken-pipe suppression.
6. `std/internal/os` owns reusable raw operating-system error categories; `std/net/errors.nct` alone
   converts network failures to public codes.

Address parsing exists only in `std/net/parsing.nct`; native address conversion exists only in the
Darwin adapter. TCP alone implements `Reader` and `Writer`; UDP retains an explicit datagram result.
The compiler's non-test sources contain no `SocketAddress`, TCP, UDP, port, socket, or network-error
semantic case. LSP queries consume the same checked identities as CLI compilation.

All partial socket constructors acquire an owner before later fallible configuration and close that
owner on failure. Accepted descriptors begin with independent unlimited timeout configuration.
Explicit close and destruction share the same terminal close-once transition. No raw errno, native
address layout, polling mask, descriptor integer, wall-clock instant, compatibility alias, or
obsolete unlimited-wait entry point crosses into the public API.
