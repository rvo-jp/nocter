**Result: complete with no open Phase 4 finding (2026-09-09).** The public example, editor

external network service or alternate HTTP implementation participates in qualification.

## Example Boundary

`examples/async-http` binds an IPv4 loopback listener on a kernel-selected port. It constructs one
POST request through public `std/http` values, then uses `task.join` to drive the client computation
and a small raw local peer concurrently. The peer accepts bounded input through the known example
body terminator, responds with one fixed body, and owns no HTTP parser or reusable server policy.
It does not depend on private client field generation or serialization order. The example checks
the final status and field before collecting the body as UTF-8 with an explicit idle timeout.

This arrangement avoids predicted ports, external DNS, Internet availability, sleeps, and an
unbounded server task. It demonstrates client interoperability without implying that `std/http`
contains a server API.

## Editor Boundary

Language-server integration obtains every signature, type hint, navigation target, and completion
entry from the checked public declaration authority. The qualification covers:

- the immediate result around `async Response!` returned by `send_async_with_timeout`;
- `Response` after `await` and result propagation;
- the `async String!` whole-body contract;
- completion of synchronous Reader operations and all asynchronous response operations; and
- exclusion of the private response decoder and completion flag.

Navigation points to `std/http/index.nct`, while the implementation body remains discoverable only
through the existing implementation/reference relation. No editor-specific HTTP signature or
source-text inference was added.
