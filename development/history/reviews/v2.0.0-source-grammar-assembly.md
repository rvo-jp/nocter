# v2.0.0 Source Grammar Assembly

## Status and Authority

This is the remaining whole-source grammar design accompanying the adopted S12–S16 boundary.
It is a non-normative assembly draft. File/item envelopes and selected module/type-operation
semantics have migrated to their owning chapters; the remaining generic, special-operation,
pack, expression, enum and package semantics must migrate before their compiler acceptance. It is not a second parser,
released grammar, implementation qualification or statement that all v2.0.0 design is complete.
The [implementation design](v2.0.0-value-binding-implementation.md) owns those entry gates.

The imported `V2*` productions are exactly those defined by the owning
[future access grammar](../../spec/language/syntactic-grammar.md#access-syntax):
values/types, input/receiver patterns, origins, callable heads/tails, binding statements, closures,
returns, throws, drops and index projections, plus the migrated file/item envelopes. The
productions below fill its remaining named whole-source dependencies.
Lexical imports are `Name`, `ModuleSegment`, literal/string/interpolation tokens, `StringLiteral`,
`EmptyStringLiteral`, `BuiltinScalarType`, trivia/newline/eof, `gap` and jointness, plus the common
`List`, `NonEmptyList`, and `LineSequence` notation. No released declaration or expression root
is imported. Generic/type syntax is not inferred from whether a name resolves as a type.

## Files, Declarations and Type Behavior: Migrated

File/import/directive and item/container productions now have one owner in
[Files and Declarations](../../spec/language/syntactic-grammar.md#files-and-declarations).
The adopted [module rules](../../spec/language/modules.md),
[type behavior](../../spec/language/type-behavior.md) and
[interface binding rules](../../spec/language/interfaces.md) own their corresponding semantics.
This draft imports those productions; it does not retain editable copies.

The migration fixes the former conformance grammar hole: associated type bindings and operation
mappings occupy one block, distinguished by a leading dot on type bindings. It does not complete
all generic, operator, literal, enum, package or platform semantics. The
[closure review](v2.0.0-module-and-operation-contracts.md) records selected consequences, examples,
remaining gates and the limit of documentation verification.

```text
V2PackageDirectives = V2PackageDirective (newline+ V2PackageDirective)*
V2PackageDirective = "#" ("package" | "dependencies" | "executable" | "test")
                      ":" V2DirectiveValue
V2DirectiveValue = StringLiteral | integer_literal | "{" List(V2DirectiveField) "}"
V2DirectiveField = Name ":" V2DirectiveValue
```

Package metadata above remains draft-owned until its complete schema and file roles migrate.

## Generic Requirements and Special Operations

```text
StructuralConstantExpression = V2Expression
V2GenericParameters = "<" NonEmptyList(V2GenericParameter) ">"
V2GenericParameter = Name | "const" Name ":" V2Type
InterfaceApplication = V2NamedType V2AssociatedBindings?
V2AssociatedBindings = "{" NonEmptyList(V2AssociatedBinding) "}"
V2AssociatedBinding = "." Name "=" V2Type
V2WhereClause = "where" V2Predicate ("," V2Predicate)*
V2Predicate = V2RequirementSubject "impl" InterfaceApplication
             | Name ":" V2Type | "copy" Name | V2Type "=" V2Type
             | "(" V2Type ("==" | "<") V2Type ")" ":" V2Type
             | "(" "edit"? V2Type "[" V2Type "]" ")" ":" V2Type
             | V2InputOperation? V2Type "as" V2Type
             | "(" "..." V2InputOperation? V2RequirementSubject ")" ":" V2Type
V2RequirementSubject = Name ("." Name)* | "Self"
V2Comparison = "operator" "(" "self" ("==" | "<") Name ":" "Self" ")"
                ":" "bool" V2WhereClause? V2Block?
V2Coercion = "coerce" V2Receiver "as" V2Type V2OriginClause? V2Block?
V2Expansion = "operator" "(" "..." V2Receiver ")" V2CallableTail V2Block?
```

The declarable operator set stays closed; comparison-derived spellings are not extra declarations.
Indexing returns a projection, not an ordinary value result; S14's owning future rules determine
read/edit selection and place-return cleanup. Equality/ordering, coercion and expansion instead
produce values under their selected receiver/input contract. New direct input retention still
needs its selected origin/state contract. Requirement spelling carries operations without retired
borrow types or authored allocation/trap/waiting guarantees. A complete checker must validate the
allowed requirement subject, associated bindings and operation family before accepting it.

The imported parameter grammar includes ordinary and named keyed final packs. A keyed pack
always has a name in callable types too: `func(... entries: K: V): R` or
`func(... take entries: K: V): R`. A one-colon `func(... K: V): R` is an ordinary named pack,
not an anonymous keyed pack. This S15 decision removes lookup-dependent ambiguity without new
punctuation. Names map to input identities and do not affect callable type equality.

Packs remain final and unique. Their schema determines whether a supplied `key: value` is a
keyed contribution. Each ordinary/keyed component uses the selected preparation operation.
Literal shape rules, spread receiver selection, dependency transport and pack ABI still require
joint semantic migration. No mutable spread assertion or standalone `move` survives.

## Blocks, Control Flow and Expressions

```text
V2Block = "{" newline* (V2LocalUses (newline+ V2Entries)? | V2Entries)? newline* "}"
V2LocalUses = ("use" V2UseTree) (newline+ "use" V2UseTree)*
V2Entries = LineSequence(V2Entry)
V2Entry = V2Statement | V2Expression
V2Statement = V2Binding | V2Return | V2Throw | V2Drop
              | V2Postfix V2AssignmentOperator V2Expression | "break" | "continue"
              | "while" V2Header V2Block | "loop" V2Block
              | "for" "await"? V2Pattern "in" V2ForSource V2Block
              | "for" Name ":" Name "in" V2Header V2Block
              | "region" Name "using" V2AllocatorPlace V2Block
V2AssignmentOperator = "=" | "+=" | "-=" | "*=" | "/=" | "%="
V2Header = V2Expression
V2ForSource = V2Header ("..<" V2Header)?
V2AllocatorPlace = Name ("." (Name | integer_literal))*
V2Expression = V2Or V2Recovery*
V2Recovery = "catch" (Name | "_") V2Block | "otherwise" V2Block
V2Or = V2And ("||" V2And)*
V2And = V2Equality ("&&" V2Equality)*
V2Equality = V2Ordering (("==" | "!=") V2Ordering)?
V2Ordering = V2Shift (("<" | "<=" | ">" | ">=") V2Shift)?
V2Shift = V2Add (("<<" | ">>") V2Add)*
V2Add = V2Multiply (("+" | "-") V2Multiply)*
V2Multiply = V2Convert (("*" | "/" | "%") V2Convert)*
V2Convert = V2Unary ("as" V2Type)*
V2Unary = ("!" | "-") V2Unary | V2Await ("?" | "!")?
V2Await = "await" V2Await | V2Postfix
V2Postfix = V2Primary V2PostfixPart*
V2PostfixPart = "(" List(V2CallArgument) ")" | "." Name | "." integer_literal
                | "[" V2Expression "]" | "." "(" V2NamedType "." Name ")"
                | V2GenericArguments "(" List(V2CallArgument) ")"
V2CallArgument = V2Expression | "..." V2Expression | V2Expression ":" V2Expression
V2Primary = Name | "Self" | BuiltinScalarType | "str" | "error"
            | integer_literal | byte_literal | "true" | "false" | "none" | "(" ")"
            | "(" V2Expression ")"
            | "(" V2Expression "," V2Expression ("," V2Expression)* ","? ")"
            | V2Closure | V2If | V2Match | V2String | V2GenericOwnerMember
            | V2Owner V2RecordBody | V2Owner gap V2SequenceBody V2AllocationOverride?
            | V2Owner gap StringLiteral V2AllocationOverride? | V2Array
V2If = "if" V2Header ("is" V2EnumPattern)? V2Block ("else" (V2Block | V2If))?
V2Match = "match" V2Header "{" LineSequence(V2MatchArm) "}"
V2MatchArm = (V2EnumPattern | "_") V2Block
V2EnumPattern = Name "." Name ("(" List(Name | "_") ")")?
V2String = string_start (string_text | interpolation_start V2Expression interpolation_end)* string_end
V2GenericOwnerMember = V2GenericOwner "." Name
V2GenericOwner = Name V2GenericArguments ("." Name V2GenericArguments?)*
                | (Name | "Self") ("." Name)* "." Name V2GenericArguments
                  ("." Name V2GenericArguments?)*
V2Owner = V2NamedType | BuiltinScalarType | "str" | "error"
V2RecordBody = "{" List(V2FieldInitializer) "}"
V2FieldInitializer = Name ":" V2Expression
V2Array = "[" (V2Expression ";" V2Expression | List(V2Expression)) "]"
V2SequenceBody = "[" (":" | List(V2SequenceElement)) "]"
V2SequenceElement = V2Expression | "..." V2Expression | V2Expression ":" V2Expression
V2AllocationOverride = "using" V2AllocatorPlace
```

`StructuralConstantExpression` is recognized as a delimiter-bounded V2 expression; checking
restricts it to the selected compile-time domain. It never imports the released expression grammar.
`V2Header` means V2Expression stopped before its first outer `{`; nested delimiters restore ordinary
expression parsing. Comparison levels allow one ungrouped operator and repeated binary levels
associate left. A string interpolation contains one expression. Blocks preserve a final value expression and unit
completion; assignment is a statement with RHS-first semantics. No semicolon suppresses a result.

An index opener is joint with its base; spaced `Owner [elements]` is typed literal construction.
An explicit generic-call `<` is joint with a name/member callee, has a syntactically complete
argument list and is followed by the call opener on that logical line. Generic owner construction
retains the same delimiter proof before a member, record body or spaced literal. Lookup cannot
reparse comparison tokens into generic arguments. Generic constant arguments use the selected
compile-time expression subset and delimiter rules; complex comparisons require grouping when a
closing generic delimiter would otherwise terminate them. Unsatisfied CTFE is a checking failure.

Field/element projections remain places when their selected operation proves that category.
Ordinary calls construct values; a call returning a capability is not silently a projection.
The explicit interface-selection suffix is permitted only when needed to resolve a collision,
not as a redundant qualified-call style. Record-literal use requires the explicit construction
grant; recognition alone is not permission to initialize public fields of an opaque representation.
The parser retains invalid-place targets for later checking, never for fallback reparsing.

## Closure and Conformance Gates

Before promoting the remaining productions, normalize their notational extensions into the owning
grammar and mechanically check the entire
nonterminal/import graph. Derive accept/reject/recovery and delimiter-depth fixtures for every
item and prefix boundary. Verify the selected source-role, audience and implementation-pairing rules as well as operator
families, pattern ownership, effect inference and cleanup against their owning chapters. Passing a grammar-graph
inventory does not prove an unambiguous parser, correct type checker or executable language.

The indexing extension is selected source design. Other rows reuse adopted vocabulary and
structural families, but this assembly does not silently adopt extra operator families, source
mode aliases, default overload ranking, hidden state retention, or more general fallible nesting.
