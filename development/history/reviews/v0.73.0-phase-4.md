# v0.73.0 Phase 4 Review: Verified Traversal Adoption

**Result: complete with no open implementation finding (2026-09-30).** Standard iteration and
scanning now expose stronger execution contracts only for operations whose complete physical bodies
cross the compiler's `notrap` validation.

## Adopted Surface

The following closed operations now publish `noalloc notrap`:

- raw-pointer identity and borrow-to-address projections certified by compiler runtime roles;
- empty and one-item iterator construction, observation, and advance;
- readonly and readwrite view-iterator construction, remaining-length observation, and advance;
- explicit readonly and readwrite `Vec` iterator construction;
- UTF-8 byte- and scalar-iterator construction without advancing the scalar iterator;
- direct byte and text window validation, cursor construction, offset and length observation;
- byte-cursor completion observation, peek, and exact optional advance; and
- text-cursor completion observation, absolute range and byte lookup, and exact boundary-aligned
  optional advance.

Concrete iterator contracts are stated next to their `impl Iterator` and `impl ExactSizeIterator`
facts. The base interfaces remain effect-neutral because an arbitrary conforming `next` or
`remaining_len` implementation may still trap.

## Arithmetic and Mutation Boundary

View iterators read the view length once, reject exhausted or defensive out-of-range state, and
subtract only on the strict surviving path. Their advance methods use the Phase 1 place model and
Phase 2 repeatable relation rules already validated for mutable cursor state.

`ByteCursor.advance_exact` first proves its stored offset is within the input, proves the requested
count fits the remaining range, and uses recoverable checked addition before committing mutation.
`TextCursor.take_bytes` performs the same steps and validates the final UTF-8 scalar boundary before
changing the cursor. Failure therefore leaves state unchanged and returns `false` or `none`; it
cannot wrap an offset or partially advance.

## Deliberate Non-adoption

The review did not add guarantees to generic iterator adapters or terminals whose selected source,
callback, comparison, or destruction contract can trap. Fixed-width scanner decoding remains
unqualified until the canonical byte decoders publish their own complete guarantees. Window-view
and remaining-view observers that currently recover an impossible private-invariant failure by
calling `safety.invariant_abort` also remain unqualified. Claiming `notrap` from constructor intent
alone would bypass body validation and reintroduce a hidden caller assumption.

## Authority Audit

Primitive execution facts remain owned once by `nocter-runtime-contract`; source declarations may
publish only compatible guarantees, and target-program validation rejects an unsupported claim.
The standard source owns range validation and checked cursor arithmetic. Checked operations carry
their trap dispositions forward, while MIR, Machine, and ARM64 do not inspect source expressions or
repeat the proof.

No backend rule, standard declaration-name fallback, unchecked public operation, or generic
guarantee inference was added. Package-private raw memory primitives remain inaccessible as user
APIs.
