# v0.40.0 Phase 5 Internet-client Integration and Final Review

**Result: implementation and source-tree qualification complete with no open v0.40.0 finding
(2026-09-07).** URL values, system host resolution, synchronous TCP, bounded HTTP/1.1 framing, and
the owned client lifecycle now cross ordinary programs, native execution, installed
standard-library use, and semantic editor queries without compiler-owned URL, DNS, or HTTP meaning.

## Practical Boundary

`examples/url-inspect.nct` is an explicit single-file program that parses one URL and prints the
canonical URL, authority, and request target from the retained value. `examples/http-get` is an
ordinary package split between a small root and one implementation source. It accepts one
`http://` URL, resolves the host through the operating system, applies finite connection and
per-operation stream timeouts, reads the bounded decoded body, and writes its exact bytes.

The recursive formatter and public-example authorities discover both additions. The single-file
corpus executes `url-inspect.nct` and compares exact output. The package registry compiles and runs
the `http-get` usage contract and rejects unregistered package directories. A separate installed-
home test builds the exact package against a copied installed standard library, connects it to a
Rust loopback fixture through `localhost`, verifies its complete request bytes, and compares status
and body output. No public Internet service, predicted free port, or test-only Nocter API is used.

## Final Authority Audit

The complete v0.40.0 path has these single authorities:

1. The closed compiler target-service catalog binds the two fixed Darwin resolver services and
   validates their ABI before Machine lowering. Generic compiler stages know only the closed
   service identity and target-independent call plan.
2. The Darwin resolver adapter alone knows `addrinfo`, native address records, resolver traversal,
   and `freeaddrinfo`. `std/net` alone validates host input, preserves usable order, removes exact
   duplicates, selects candidate fallback, and maps public network errors.
3. `std/url` retains one canonical component representation. Parsing, resolution, equality,
   hashing, complete formatting, Host authority, and request-target projection consume that value;
   HTTP never reparses URL text.
4. The private response-head decoder owns received head input, the scan cursor, completed fields,
   informational-response count, and the one body-framing decision. The body decoder carries that
   decision and its finite limits into every body read. Lower-level codec helpers know neither
   transport ownership nor resolver contracts.
5. The HTTP client alone owns generated Host, Connection, and Content-Length fields plus the
   one-request connection lifecycle. One private `PreparedRequest` seals the consumed request,
   exact encoded head, and selected limits so a caller cannot mismatch them.
6. `Response` uniquely owns the TCP stream, framing decoder, unread input, and reusable read buffer.
   Decoder completion, failure, explicit close, and destruction all reach the same terminal stream
   closure policy.

The initial integration review found and corrected two defects. The first response reader called
the decoder only when buffered bytes existed, so an input-independent bodyless state could wait on
a peer that correctly kept its side open. The final reader always lets the decoder advance before
requesting transport input. The first send boundary accepted a request, separately encoded bytes,
and limits whose correspondence depended on its caller; `PreparedRequest` now makes an invalid
combination unrepresentable and centralizes HTTPS, CONNECT, reserved-field, and framing policy for
both ordinary and timeout sends.

The final whole-area review then reopened Phase 5 and corrected four deeper issues. Response-head
parsing had been stateless: every partial read reparsed the complete retained prefix, repeated
field allocation, and made adversarial fragmentation quadratic. One input-owning decoder now
retains its cursor and completed semantic fields, accepts only validated source ranges, and is
tested at every single split boundary. Informational responses had no aggregate count bound; the
same `Limits` value now bounds both each head and the number of provisional heads. URL-reference
resolution first allocated and normalized discarded components, and authority replacement eagerly
copied the base host; non-owning source ranges now classify the reference before only the selected
components are constructed. Registered-host percent escapes previously retained URI spelling for
the operating-system resolver; accepted ASCII host octets are now decoded and canonicalized once,
while non-ASCII and structurally invalid octets are rejected. Finally, chunk quoted-pair parsing
accepted escaped control bytes through a duplicate predicate; field and chunk parsing now share
one byte-validation authority.

A follow-up ownership audit found that the first incremental decoder still depended on its caller
reusing one append-only buffer. The decoder now owns all received input and exposes only a
range-validated append operation. Transport code can no longer invalidate its cursor or pair its
state with unrelated bytes.

The client uses one reusable transport scratch allocation; the response-head decoder owns its
accumulated input, and each `Response` owns one reusable body-read buffer. Network read loops no
longer allocate a fresh 8 KiB vector per operation. A bounded informational sequence may retain its
consumed prefix until the final head transfers the input into `Response`, but both its per-head
growth and response count are finite. Every attacker-controlled head, field, chunk line, trailer,
and decoded body remains bounded.

Searches over production compiler sources find no URL, DNS, or HTTP semantic branch. The only
unrelated HTTP framing vocabulary is the LSP transport's own protocol parser. Searches over the
transport-neutral HTTP codec find no network type or operation. No compatibility spelling,
duplicate URL parser, custom DNS client, second HTTP framing selector, raw native record, or
caller-enforced hidden lifecycle precondition remains.
