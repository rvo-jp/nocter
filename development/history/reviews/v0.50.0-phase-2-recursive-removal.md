# v0.50.0 Phase 2 Recursive-removal Review

Date: 2026-09-14

## Result

`std/fs.remove_dir_all` and its explicit blocking twin now remove a complete directory tree without
recursive calls or following symbolic links. Both use a depth-first state machine with one owning
directory stream per retained level and a fixed maximum depth of 256.

## Authority Review

- `ReadDir` and `BlockingReadDir` remain the only directory descriptor and record-decoding owners.
  Recursive removal composes their public step contracts rather than introducing another directory
  syscall or record parser.
- Directory opening now includes the target no-follow flag as part of its existing semantic access
  role. Generated ARM64 code and host conformance each implement that target boundary; filesystem
  policy never constructs the numeric flag.
- `recursive_removal.nct` alone owns traversal order, the depth bound, entry reclassification, and
  partial-progress policy. `directory_entry_path` is a narrow internal projection from the private
  `DirEntry` representation to its already-owned path text.
- Each entry is classified through final-link metadata before descent. Directory-record type hints
  therefore do not become the recursive deletion authority, and unknown target hints cannot skip a
  directory subtree.

## Failure, Race, and Cancellation Review

The supplied root must itself be a directory. A root symbolic link fails with
`std.io.not_directory`; a symbolic link below the root is unlinked and its target is untouched.
Directory open rejects a final link even if it replaces an entry after metadata observation.
Ancestor path components remain ordinary target path lookup and are not a capability-secure
filesystem sandbox.

Removal is deliberately non-transactional. I/O failure, malformed input, allocation termination,
depth rejection, or asynchronous cancellation preserves removals already observed. Stack
destruction closes every retained stream. An in-flight asynchronous directory operation retains
its descriptor through the existing job retirement authority and cannot publish into an abandoned
caller buffer.

## Verification

Native standard tests cover nested depth-first removal, preservation of an externally targeted
directory through an interior symbolic link, and rejection of a symbolic-link root. A complete
native asynchronous session removes a nested tree. Runtime/ARM64 and host conformance cover the
no-follow directory access, while semantic-editor coverage resolves the public blocking contract.
