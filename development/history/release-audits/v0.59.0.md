## Post-Publication Audit

The asset was downloaded from its public release URL into a new disposable directory. It compared
byte for byte with the qualified local candidate, and its independently computed SHA-256 matched
both the candidate record and GitHub's asset digest. The downloaded archive extracted to a valid
Nocter home whose compiler reported release `0.59.0`, host `arm64-darwin`, and default target
`arm64-darwin`.

The public latest-release endpoint resolved to `v0.59.0`. The public annotated tag resolves to the
exact publication commit recorded above, and remote `main` contained that same commit when the
audit ran.

GitHub Pages uses its Actions source. Documentation run `35365204380` completed successfully and
artifact `10556470107` deployed 321 generated pages from the publication commit. During the
post-publication audit, `deployment.json` named source revision
`b4b51bf867aaaca6449dd90203121d85374b5438`; the served homepage selected v0.59.0 and its exact
release asset.

The release asset and tag are immutable by project policy. Any correction after v0.59.0 requires a
new version, a new tag, a new qualification run, and a newly published archive; the existing tag
and asset must not be replaced.
