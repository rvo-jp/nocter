## Post-Publication Audit

The asset was downloaded from its public release URL into a new disposable directory. It compared
byte for byte with the qualified local candidate, and its independently computed SHA-256 matched
both the candidate record and GitHub's asset digest. The downloaded archive extracted to a valid
Nocter home whose compiler reported release `0.50.0`, host `arm64-darwin`, and default target
`arm64-darwin`.

The public latest-release endpoint resolved to `v0.50.0`. The public annotated tag resolves to the
exact publication commit recorded above, and remote `main` contained that same commit when the
audit ran.

GitHub Pages uses its Actions source. Documentation run `34838332817` completed successfully and
artifact `10344702990` deployed 290 generated pages from the publication commit. During the
post-publication audit, `deployment.json` named source revision
`757d4bed45a8ebf490165f0d36fa2e8425167a10`; the served homepage selected v0.50.0, used the
site-owned hero, and did not contain the repository-only README presentation block. Later `main`
deployments carry their own exact source revision rather than preserving this historical value.

The release asset and tag are immutable by project policy. Any correction after v0.50.0 requires a
new version, a new tag, a new qualification run, and a newly published archive; the existing tag
and asset must not be replaced.
