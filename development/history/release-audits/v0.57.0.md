byte for byte with the qualified local candidate, and its independently computed SHA-256 matched
both the candidate record and GitHub's asset digest. The downloaded archive extracted to a valid
Nocter home whose compiler reported release `0.57.0`, host `arm64-darwin`, and default target
`arm64-darwin`.

The public latest-release endpoint resolved to `v0.57.0`. The public annotated tag resolves to the
exact publication commit recorded above, and remote `main` contained that same commit when the
audit ran.

GitHub Pages uses its Actions source. Documentation run `35265678520` completed successfully and
artifact `10515993359` deployed 309 generated pages from the publication commit. During the
post-publication audit, `deployment.json` named source revision
`33aff8d8a56c3481a6d8137cddd957c1723d65ea`; the served homepage selected v0.57.0 and its exact
release asset.

The release asset and tag are immutable by project policy. Any correction after v0.57.0 requires a
