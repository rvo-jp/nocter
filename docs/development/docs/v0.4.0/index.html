use std/io.print

func greet(user: User): void! {
    let name = user.display.name() otherwise { "guest" }

    let tone = match user.presence {
        Presence.online { "hello" }
        Presence.away { "welcome back" }
    }

    print("${tone}, ${name}\n")?
}
interface Writer {
    pub method &+self.write(bytes: &[u8]): void!
}

func save_log(output: &+Writer, events: &[Event]): void! {
    for event in events {
        output.write(event.message().bytes())?
        output.write("\n".bytes())?
    }
}
pub struct Session {
    id: SessionId
    user: User
    expires_at: Time
}

pub func Session.start(user: User, clock: &Clock): Session {
    return Session {
        id: SessionId.new(),
        user: move user,
        expires_at: clock.now().plus_minutes(30),
    }
}
struct Profile {
    ...UserSummary
    ...ActivityStats
    visits: u32
}

func profile(user: &User, stats: ActivityStats): Profile {
    return Profile {
        ...user.summary(),
        ...move stats,
        visits: 0,
    }
}
literal NonEmptyList<T> [first: T, ...rest: [T]]: Self {
    let list = Self.with_first(move first)

    for item in rest {
        list.push(move item)
    }

    return list
}

Nocter v0.4.0 Development Plan

Purpose

v0.4.0 makes a source-owned package the unit shared by the compiler, command-line tools, and editor integration. Package structure is declared in index.nct; Nocter does not add a separate manifest language or infer an executable from a conventional filename.

v0.4.0 Phase 0: Source-Native Package Roots and Executable Targets is complete. Later phases may add dependency resolution, package-wide incremental analysis, and workspace editor operations on top of the identities established here.

Active Phase 0 Outcome

Phase 0 is complete when:

  • index.nct is the explicit root of a source package
  • a leading package header declares package metadata and zero or more executable targets
  • #name, #version, and #executable use declarative directive values
  • declaration directives use the same #name: value spelling, including #target: "arm64-darwin"
  • #name defaults to the package-root directory name only for presentation
  • #version may be absent and is never replaced by an invented version
  • each executable names a logical module, without a .nct suffix, whose root declaration is func main
  • nocter check, nocter build, and nocter run select a package and executable without probing for main.nct
  • explicit positional or --file single-file operation remains a separate, explicit script input and never changes package-default discovery
  • pub use ./path publicly re-exports one module namespace rather than flattening its names
  • parser, formatter, JSON AST, resolver, analysis, diagnostics, LSP, native execution, and packaged execution agree on the new source forms

The detailed contract is in Source-Native Package Roots.

Phase 0 Work Order

  1. 1. Freeze package-root, directive-data, executable-selection, module re-export, CLI, diagnostic, editor, and non-goal contracts.
  2. Introduce focused AST and parser responsibilities for package headers and declarative values.
  3. Introduce compiler-owned package, module, and executable identities without using display names or path strings interchangeably.
  4. Load index.nct, validate its header, and resolve each executable module before ordinary compile-unit analysis.
  5. Replace implicit main.nct command selection with package and executable selection.
  6. Promote public namespace re-exports through resolver, analysis, formatter, and LSP identity paths.
  7. Migrate #target(...) atomically to #target: ... in compiler tests, distributed standard library source, specification, and generated documentation.
  8. Pass the repository-home and packaged-home acceptance matrix and stabilize malformed-input behavior.

Phase 0 Non-goals

  • #depend resolution, source acquisition, package stores, registries, or lock data
  • multi-package workspaces
  • package-wide incremental invalidation, rename, code actions, or inlay hints
  • test-target declarations or a package test runner
  • source-level region parameters, mutable lending iteration, runtime interface dispatch, async execution, concurrency, or a new native target

The #depend record shape is reserved by the v0.4.0 direction, but dependency-bearing builds are not accepted as complete until the later dependency phase owns source identity, retrieval, caching, cycles, and offline behavior together.

Verification Gate

Phase 0 requires the full compiler verification script, formatter, warnings-denied Clippy, public documentation generation, native CLI and LSP integration tests, optimized local distribution, installed-home doctor, packaged-home package execution, archive inspection, and a clean worktree.

Completion Record

Phase 0 completed on 2026-08-05. The final gate passed:

  • compiler check, all unit and integration tests, formatter verification, and warnings-denied Clippy
  • native package check, build, run, multiple-target selection, library-only behavior, and rejection of undeclared main.nct
  • parser, formatter, JSON AST, resolver, public namespace re-export, and LSP range/navigation tests
  • generated public documentation
  • optimized local distribution, installed-home doctor, packaged-home package check/build/run, direct execution of the generated ARM64 Mach-O, and archive inspection

Dependency resolution remains deliberately outside this completion record.
